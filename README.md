# Linux Administration

Учебная практика администрирования Linux в Школе 21. Репозиторий содержит отчёт с командами, пояснениями и скриншотами работы в виртуальной машине.

**[Открыть отчёт →](src/proj_DO1_Linux.md)**

## Содержание работы

- Пользователи, группы и права sudo.
- Сетевые интерфейсы, DHCP, статическая настройка через Netplan.
- Обновление системы, синхронизация времени, текстовые редакторы.
- Настройка SSHd и просмотр журналов службы.
- Диагностика процессов: top и htop.
- Диски и файловая система: fdisk, df, du, ncdu.
- Системные журналы и задания cron.

## Формат проекта

Это отчёт по учебной лабораторной, а не автоматизированная установка сервера. Для просмотра достаточно открыть Markdown-отчёт; команды изменения сети, SSH и пользователей предназначены для отдельной учебной VM.
